# \# React Games

# 

# A repository containing two interactive games built with React and JavaScript:

# 

# \* \*\*Tenzies\*\* – Roll ten dice and try to get all dice showing the same number.

# \* \*\*Assembly Hangman\*\* – Guess the hidden word before running out of attempts.

# 

# \## Getting Started

# 

# \### Prerequisites

# 

# \* \[Node.js](https://nodejs.org/) installed

# \* npm installed

# 

# \### Installation

# 

# Clone the repository and navigate into the game you want to play:

# 

# ```bash

# git clone <repository-url>

# cd <repository-name>

# ```

# 

# Each game is a separate Node project with its own dependencies.

# 

# \### Tenzies

# 

# ```bash

# cd tenzies

# npm install

# npm run dev

# ```

# 

# Open the local URL provided by Vite in your browser.

# 

# \### Assembly Hangman

# 

# From the repository root:

# 

# ```bash

# cd assembly-hangman

# npm install

# npm run dev

# ```

# 

# Open the local URL provided by Vite in your browser.

# 

# \## How to Play

# 

# \### Tenzies

# 

# 1\. Roll the dice.

# 2\. Click dice to hold them.

# 3\. Roll again to reroll the unheld dice.

# 4\. Continue holding matching numbers until all ten dice show the same value.

# 5\. Win by matching all ten dice.

# 

# \### Assembly Hangman

# 

# 1\. A hidden word is randomly selected.

# 2\. Select letters to guess the word.

# 3\. Correct guesses reveal the corresponding letters.

# 4\. Incorrect guesses cause an assembly language to be removed.

# 5\. Guess the word before all assembly languages are eliminated to win.
